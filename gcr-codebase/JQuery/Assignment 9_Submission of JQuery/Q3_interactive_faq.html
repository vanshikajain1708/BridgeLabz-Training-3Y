What is jQuery?

jQuery is a fast JavaScript library that makes DOM handling and events simple.

How do I include jQuery in a page?

Add a script tag that points to the jQuery file (CDN or local) before your own script.

What does $(document).ready() do?

It runs your code only after the HTML document has finished loading.

What is event delegation?

Attaching one event listener to a parent so it can handle events of current and future children.

Is jQuery still used today?

Yes, many existing websites still use it, so it is useful to know.
